# Jaehwan Choi — personal website

A lightweight English academic homepage for GitHub Pages. It uses plain HTML, CSS and a small amount of JavaScript, with no build step.

## Preview locally

Run `python3 -m http.server 8765` in this directory, then open `http://localhost:8765`.

## Live site

The site is published at https://jaehwanmicc.github.io/ from the `main` branch at the repository root. The source repository is https://github.com/jaehwanmicc/jaehwanmicc.github.io. Changes pushed to `main` are published by GitHub Pages.

The owner supplied the portrait, public email, LinkedIn and Google Scholar profile links, and Korea University education details. The publication list currently contains the 11 works supplied by the owner. Journal impact factors link to their publishers and were checked in September 2026; update these figures when the publishers release new metrics. The headshot was supplied by the site owner; embedded metadata was removed from the site copy.
