# Jaehwan Choi — personal website

A lightweight English academic homepage for GitHub Pages. It uses plain HTML, CSS and a small amount of JavaScript, with no build step.

## Preview locally

Run `python3 -m http.server 8765` in this directory, then open `http://localhost:8765`.

## Publish

This repository belongs to `jaehwanmicc` but is named `jaehwanchoi.github.io`. For the short user-site address `https://jaehwanmicc.github.io/`, rename the repository to `jaehwanmicc.github.io`, put the files on its default branch, and enable GitHub Pages in **Settings → Pages → Deploy from a branch → main / (root)**. Keeping the current repository name instead yields a project-site URL under `jaehwanmicc.github.io/jaehwanchoi.github.io/`.

Before publishing, review the biography, publication ordering and public email address. Education dates, awards, CV and a direct Google Scholar profile link can be added when verified. The headshot was supplied by the site owner; embedded metadata was removed from the site copy.
